# Wyrmhole supporters

Public supporter names for the Wyrmhole Project thank-you board in VRChat.

The Ko-fi webhook receiver runs separately on the project web server and updates `supporters.json`. This repository contains only public names. It contains no credentials, payment information, or world-access permissions.

Enable GitHub Pages from the `main` branch and repository root. The world reads:

https://aerowolf1.github.io/wyrmhole-supporters/supporters.json

The whitelist remains in its separate access repository. No supporter update grants world permissions.
